README del progetto

Nessun documento corrisponde alla ricerca.

Il sito è generato dai dati di assets/indice.js: per aggiungere un nuovo argomento basta inserire il file HTML nella cartella giusta e aggiungere la corrispondente voce in quell'elenco, senza modificare gli altri file.

I documenti restano HTML autonomi e stampabili in A4; ognuno di essi propone in alto il link di ritorno a questa pagina.
