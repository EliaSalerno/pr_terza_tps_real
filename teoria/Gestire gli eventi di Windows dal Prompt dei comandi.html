Gestire gli eventi di Windows dal Prompt dei comandi

Guida ai comandi CMD per leggere, filtrare, esportare, configurare e creare eventi del Visualizzatore eventi. Il comando principale è wevtutil.

Preparazione

Cerca cmd nel menu Start, clic destro e scegli Esegui come amministratore. Molte operazioni (registro Sicurezza, cancellazione, configurazione) richiedono questi privilegi.

I comandi che modificano o cancellano i registri sono irreversibili. Prima di usarli, esporta una copia con wevtutil epl.

Elencare i registri

Vedere tutti i registri disponibili

Mostra i nomi di tutti i registri eventi presenti nel sistema (sono centinaia). el significa enumerate logs.

wevtutil el

Per cercare un registro per nome, filtra l’output con find:

wevtutil el | find /i "powershell"

Leggere gli eventi

Ultimi 10 eventi del registro Sistema

wevtutil qe System /c:10 /rd:true /f:text
  • qe: query events, cioè legge gli eventi
  • System: nome del registro
  • /c:10: numero massimo di eventi da mostrare
  • /rd:true: ordine inverso, dal più recente al più vecchio (false è il predefinito)
  • /f:text: formato leggibile; senza questa opzione l’output è in XML

Leggere un solo evento alla volta, con pausa

Utile quando l’output è lungo: more mostra una schermata per volta (barra spaziatrice per avanzare).

wevtutil qe Application /c:20 /rd:true /f:text | more

Salvare l’output in un file di testo

wevtutil qe System /c:50 /rd:true /f:text > C:\temp\eventi_sistema.txt

Il simbolo > reindirizza il risultato nel file. La cartella C:\temp deve esistere.

Leggere un file .evtx esportato

Con /lf:true il nome indicato è un file di log e non un registro di sistema.

wevtutil qe C:\temp\system.evtx /lf:true /c:10 /f:text

Filtrare gli eventi

Il filtro si passa con /q: usando la sintassi XPath. La forma generale è "*[System[(condizione)]]". Le virgolette sono obbligatorie.

Solo gli errori

wevtutil qe Application /q:"*[System[(Level=2)]]" /c:20 /rd:true /f:text

Errori e avvisi insieme

wevtutil qe System /q:"*[System[(Level=2 or Level=3)]]" /c:20 /rd:true /f:text

Un ID evento specifico

Esempio: l’ID 41 indica un riavvio imprevisto (Kernel-Power), l’ID 6008 un arresto anomalo precedente.

wevtutil qe System /q:"*[System[(EventID=41)]]" /c:5 /rd:true /f:text

Eventi dell’ultima ora

timediff è espresso in millisecondi: 3600000 ms = 1 ora. Per 24 ore usa 86400000.

wevtutil qe System /q:"*[System[TimeCreated[timediff(@SystemTime) <= 3600000]]]" /rd:true /f:text

Errori di una specifica origine

Filtra per nome del provider (la sorgente dell’evento), qui il servizio Service Control Manager.

wevtutil qe System /q:"*[System[Provider[@Name='Service Control Manager'] and Level=2]]" /c:10 /rd:true /f:text

Accessi falliti (registro Sicurezza)

L’ID 4625 registra i tentativi di accesso non riusciti. Richiede prompt come amministratore.

wevtutil qe Security /q:"*[System[(EventID=4625)]]" /c:10 /rd:true /f:text

Esportare, importare, archiviare

Esportare un registro in un file .evtx

epl significa export log. Il file si può aprire in seguito con il Visualizzatore eventi, anche su un altro PC.

wevtutil epl System C:\temp\system.evtx

Esportare solo gli eventi filtrati

wevtutil epl System C:\temp\errori.evtx /q:"*[System[(Level=2)]]"

Archiviare un registro con le informazioni di lingua

al (archive log) salva il registro in modo che resti leggibile su altri computer, anche con lingua di sistema diversa.

wevtutil al C:\temp\system.evtx /l:it-IT

Configurare i registri

Vedere la configurazione di un registro

gl (get log) mostra dimensione massima, politica di sovrascrittura e stato.

wevtutil gl Application

Vedere lo stato e le dimensioni attuali

gli (get log info) indica numero di eventi, dimensione del file e data dell’ultima scrittura.

wevtutil gli System

Cambiare la dimensione massima

Il valore è in byte. Qui 100 MB (104857600 byte). Richiede amministratore.

wevtutil sl Application /ms:104857600

Abilitare o disattivare un registro

wevtutil sl "Microsoft-Windows-TaskScheduler/Operational" /e:true

Con /e:false il registro viene disattivato. Il registro Task Scheduler, per esempio, è spesso disabilitato per impostazione predefinita.

Comportamento a registro pieno

/rt:true (retention) conserva gli eventi e smette di scrivere quando il registro è pieno. Con /rt:false gli eventi più vecchi vengono sovrascritti.

wevtutil sl Application /rt:false

Cancellare i registri

Svuotare un registro

cl (clear log) elimina tutti gli eventi. Con /bu: crea prima un backup.

wevtutil cl Application /bu:C:\temp\application_backup.evtx
Non esiste annullamento. Cancellare il registro Sicurezza genera a sua volta l’evento 1102, quindi l’operazione resta tracciata.

Svuotare tutti i registri

Il ciclo for legge l’elenco dei registri e li cancella uno per uno. Gli errori su registri non cancellabili sono normali.

for /f "tokens=*" %L in ('wevtutil el') do wevtutil cl "%L"

In un file .bat bisogna raddoppiare il simbolo: %%L al posto di %L.

Creare eventi personalizzati

Scrivere un evento nel registro Application

eventcreate /T ERROR /ID 100 /L APPLICATION /SO MiaApp /D "Messaggio di prova"
  • /T: tipo, uno tra ERROR, WARNING, INFORMATION
  • /ID: numero evento, da 1 a 1000
  • /L: registro di destinazione (APPLICATION o SYSTEM)
  • /SO: nome della sorgente, libero
  • /D: testo della descrizione

Utile negli script batch per lasciare traccia di operazioni, per esempio un backup completato.

Creare l’evento su un computer remoto

eventcreate /S NOMEPC /U utente /T INFORMATION /ID 200 /L APPLICATION /SO MiaApp /D "Test remoto"

Se ometti /P, la password viene richiesta in modo nascosto.

Aprire il Visualizzatore eventi

Aprire la console grafica

eventvwr.msc

Per leggere un file .evtx direttamente nella GUI: eventvwr.msc /l:"C:\temp\system.evtx".
