Windows e il Prompt dei comandi

Come è fatto Windows, come si legge un percorso, che cos'è una shell e come si lavora da Prompt dei comandi: creare, modificare e leggere file e cartelle, spegnere il PC, vedere le proprietà dell'utente connesso, avviare un programma con un'altra identità e — perché no — qualche comando simpatico da mostrare in classe.

Questa dispensa accompagna le attività su utenti, gruppi e permessi. Non serve imparare a memoria tutto: l'obiettivo è capire come funziona il sistema e dove si trovano le informazioni, sapendo poi cercare l'opzione giusta con /?.

1. Che cos'è Windows

Windows è un sistema operativo: il software che si mette tra l'hardware del computer e i programmi, gestendo processore, memoria, dischi, rete, utenti e permessi. Le versioni moderne (Windows 10, Windows 11, Windows Server) appartengono alla famiglia Windows NT, la stessa architettura pensata fin dall'inizio per la sicurezza, i profili utente e il multitasking.

Le differenze tra le edizioni non sono solo estetiche. Contano per il laboratorio:

EdizioneA cosa serveCosa manca
HomeUso domesticoNiente Utenti e gruppi locali, niente Criteri di sicurezza locali, niente ingresso in dominio
ProUfficio, laboratorio, scuole—
Enterprise / EducationGrandi organizzazioni—
Perché Windows 11 Pro in laboratorio. Solo le edizioni Pro, Enterprise ed Education hanno la console Utenti e gruppi locali, i Criteri di sicurezza locali e la possibilità di entrare in un dominio. Con la Home alcune attività non si possono fare.

Tre parole che tornano sempre:

Kernel

Il cuore del sistema: gestisce processi, memoria e accesso all'hardware.

Registro di sistema

Un grande archivio di configurazione, fatto di chiavi e valori, che Windows e i programmi consultano all'avvio.

Servizi

Programmi che girano in background senza interfaccia (rete, stampa, aggiornamenti). Si vedono in services.

2. Dischi, file system e percorsi

I dati vivono su unità indicate da una lettera: C: è in genere il disco di sistema, D: un secondo disco o una partizione, E: una chiavetta o un lettore ottico. Il file system quasi sempre usato da Windows è NTFS, che supporta permessi, quote, cifratura e journaling. I supporti rimovibili possono usare FAT32 o exFAT (senza permessi NTFS).

Un percorso indica dove si trova un oggetto. Può essere:

  • assoluto, cioè completo: C:\Users\admin\Documenti\relazione.txt;
  • relativo, cioè rispetto alla cartella in cui ci si trova: Documenti\relazione.txt oppure ..\altro.txt.

Simboli utili:

SimboloSignificato
\Separatore di cartelle su Windows (su Linux e macOS è /)
.La cartella corrente
..La cartella superiore (padre)
\ all'inizioRadice dell'unità corrente: \Windows è C:\Windows se sei su C:
%USERPROFILE%La cartella del profilo dell'utente connesso, es. C:\Users\admin
* e ?Caratteri jolly: * = qualsiasi sequenza, ? = un solo carattere

Ogni file ha un nome, un'estensione (le lettere dopo il punto, come .txt, .exe, .jpg) e degli attributi (sola lettura, nascosto, di sistema, archivio, compresso, cifrato). Nome ed estensione sono solo etichette: il tipo vero lo decide il contenuto, non l'estensione.

Estensioni nascoste. Windows, di default, nasconde le estensioni conosciute. Conviene mostrarle (scheda Visualizza di Esplora file): un file che sembra foto.jpg potrebbe essere davvero foto.jpg.exe, cioè un programma.

3. Le shell: cmd, PowerShell e Windows Terminal

Una shell è un programma che legge i comandi scritti dall'utente, li esegue e mostra il risultato. Windows ne ha più di una:

ShellProgrammaQuando si usa
Prompt dei comandi (CMD)cmd.exeComandi "storici" di Windows: dir, copy, net, icacls, shutdown
PowerShellpowershell.exeAutomazione moderna: comandi a oggetti (cmdlet) come Get-ChildItem, scripting
Windows Terminalwt.exeContenitore moderno che apre più schede: CMD, PowerShell, WSL…

Da CMD si può sempre richiamare PowerShell con powershell -Command "...", e da PowerShell si possono lanciare i comandi classici. In questa dispensa si usa quasi sempre il Prompt dei comandi.

Come si apre il Prompt dei comandi

  • Win + R, scrivere cmd, Invio.
  • Menu Start → cercare "Prompt dei comandi".
  • In Esplora file, nella barra degli indirizzi, scrivere cmd e premere Invio: si apre il prompt già dentro quella cartella.
  • Maiusc + clic destro su una cartella → Apri in Terminale.
Prompt come amministratore. Molte operazioni (utenti, permessi, spegnimento programmato, servizi) richiedono privilegi elevati. Si apre con clic destro sull'icona → Esegui come amministratore. Il titolo della finestra riporta Amministratore. Senza, il comando risponde "Accesso negato".

4. Leggere il prompt e le regole di base

Quando si apre il prompt compare una riga come questa: è il prompt, cioè l'invito a scrivere. Non è parte del comando.

Microsoft Windows [Versione 10.0.22631.3155]
(c) Microsoft Corporation. Tutti i diritti riservati.

C:\Users\admin> _

Si legge così: C:\Users\admin è la cartella corrente, > indica che il sistema è pronto. Dopo aver premuto Invio, il comando viene eseguito e il prompt ricompare. In PowerShell la riga comincia con PS: PS C:\Users\admin>.

Variabili d'ambiente

Windows tiene da parte alcune informazioni riutilizzabili, dette variabili d'ambiente. Si scrivono tra segni di percentuale:

VariabileContiene
%USERNAME%Il nome dell'utente connesso
%USERPROFILE%La cartella del profilo, es. C:\Users\admin
%COMPUTERNAME%Il nome del computer
%TEMP%La cartella dei file temporanei
%PATH%Gli elenchi di cartelle in cui Windows cerca i programmi
%CD%La cartella corrente
%ERRORLEVEL%Il codice di uscita dell'ultimo comando (0 = riuscito)

Il comando set, senza argomenti, elenca tutte le variabili; set NOME=valore ne crea una per la sessione corrente.

Redirezione, pipe e concatenazione

OperatoreEffetto
>Scrive l'output in un file, sovrascrivendolo (es. dir > elenco.txt)
>>Aggiunge l'output in fondo a un file
<Prende l'input da un file
2>Redirige gli errori (es. 2> errori.txt)
|Pipe: l'output di un comando diventa l'input del successivo (es. dir | findstr txt)
&& / &Esegue il secondo comando solo se il primo è riuscito / in ogni caso

Chiedere aiuto

Quasi ogni comando accetta /? per mostrare la sintassi completa: dir /?, shutdown /?, copy /?. È la prima cosa da fare quando un'opzione non si ricorda.

6. Creare cartelle e file

Cartelle

mkdir Lavoro
md Lavoro\Progetto\Documenti

mkdir e md sono lo stesso comando. Con le "estensioni comandi" attive (default), una sola chiamata crea anche le cartelle intermedie, come nel secondo esempio.

File

ComandoRisultato
echo Ciao > saluto.txtCrea (o sovrascrive) un file con una riga di testo
echo Ciao >> saluto.txtAggiunge la riga in fondo al file
type nul > vuoto.txtCrea un file vuoto
fsutil file createnew prova.dat 0Crea un file di dimensione stabilita in byte (qui 0)
copy con appunti.txtMetodo storico: scrive da tastiera fino a Ctrl+Z. Ancora utile, ma scomodo
Il file non si "crea" davvero a vuoto. In Windows un file nasce quando ci si scrive qualcosa: per questo echo con la redirezione è il modo più semplice. type nul > file sfrutta il fatto che nul è il "dispositivo nullo".

7. Copiare, spostare, rinominare, eliminare

ComandoCosa fa

xcopy C:\Dati D:\Backup /E /I /HCopia anche le sottocartelle (/E), crea la destinazione (/I), include i nascosti (/H)

9. Spegnere e riavviare: il comando shutdown e tutte le opzioni

Il comando shutdown spegne o riavvia il computer locale o uno remoto, con un eventuale conto alla rovescia e una motivazione. È utilissimo in laboratorio e in dominio per pianificare gli arresti.

Sintassi completa:

shutdown [/i | /l | /s | /sg | /r | /g | /a | /p | /h | /e | /o] [/hybrid] [/fw] [/f] [/m \\computer] [/t xxx] [/d [p|u:]xx:yy [/c "commento"]]
OpzioneSignificato
/iMostra la finestra grafica Arresto remoto. Se presente deve essere la prima opzione e le altre vengono ignorate
/lDisconnette l'utente corrente, senza spegnere il PC. Non combinabile con altre opzioni
/sSpegne il computer
/sgSpegne il computer; al successivo avvio, se abilitato, esegue l'accesso automatico e blocca la sessione
/rSpegne e riavvia
/gArresto completo e riavvio, con ripristino delle app registrate dopo l'accesso automatico
/aAnnulla un arresto già pianificato (va eseguito in un'altra finestra durante il conto alla rovescia)
/pSpegne subito, senza attesa né avviso; solo per il computer locale, utilizzabile solo con /d o /f
/hMette il computer in ibernazione (se abilitata)
/hybridArresto ibrido, cioè prepara l'avvio rapido; si usa con /s
/fwAl successivo riavvio entra nell'interfaccia del firmware (BIOS/UEFI)
/eDocumenta la causa di un arresto imprevisto nel Shutdown Event Tracker
/oRiavvia entrando nel menu delle opzioni di avvio avanzate; si usa con /r
/fForza la chiusura delle applicazioni senza avvisare. Si perdono i dati non salvati
/m \\computerIndica il computer di destinazione (remoto)
/t xxxAttesa in secondi prima dell'arresto (default 30). Se > 0, /f è implicito
/d [p|u:]xx:yyMotivo dell'arresto: p pianificato, u definito dall'utente, xx causa maggiore, yy causa minore
/c "commento"Commento personalizzato (max 512 caratteri), mostrato nel registro eventi
/?Mostra l'aiuto e l'elenco dei codici di motivo disponibili

Esempi pronti all'uso

REM Spegni tra 60 secondi, avvisando gli utenti
shutdown /s /t 60 /c "Manutenzione programmata"

REM Annulla lo spegnimento pianificato (in un'altra finestra)
shutdown /a

REM Riavvia subito forzando la chiusura delle app
shutdown /r /t 0 /f

REM Spegni e prepara l'avvio rapido
shutdown /s /hybrid /t 0

REM Riavvia entrando nel menu di avvio avanzato
shutdown /r /o /t 0

REM Disconnetti l'utente corrente
shutdown /l

REM Riavvia un altro PC della rete, con motivo pianificato
shutdown /r /m \\WINDOWS-2 /t 30 /c "Aggiornamento" /d p:4:1
Attenzione agli scherzi. shutdown /s /t 0 spegne davvero, e /f chiude i programmi senza salvare. Un "semplice" shutdown lanciato su un PC altrui è un attacco, non uno scherzo: in laboratorio si prova solo sulla propria macchina virtuale, e con uno snapshot pronto.

Per la sola disconnessione, in alternativa c'è logoff.

10. Le proprietà dell'utente connesso

Il comando principale è whoami ("chi sono io"): mostra utente, gruppi e privilegi dell'account connesso.

ComandoCosa mostra
whoamiDominio (o computer) e nome utente, es. windows-1\admin
whoami /userNome utente e SID (l'identificativo interno dell'account)
whoami /groupsI gruppi a cui appartiene l'utente, con i rispettivi SID
whoami /privI privilegi presenti nel token di accesso (abilitati o disabilitati)
whoami /claimsLe attestazioni (claims) dell'utente
whoami /allTutto: utente, SID, gruppi, privilegi e attestazioni
whoami /upn / /fqdn / /logonidNome in formato UPN, FQDN, oppure ID di accesso
whoami /fo list / /fo csv / /nhFormato di output (tabella, elenco, CSV) e niente intestazioni

Altre informazioni utili sull'utente e sulla sessione:

REM Riepilogo dell'account corrente (nome, scadenza password, ultimo accesso...)
net user %USERNAME%

REM Sessioni aperte sul computer (utente, sessione, stato, ora)
query user
query session

REM Riepilogo generale del sistema (edizione, RAM, processore, data di installazione)
systeminfo

REM Solo alcune righe
systeminfo | findstr /C:"Nome host" /C:"Versione SO" /C:"Memoria fisica"

REM Variabili d'ambiente dell'utente e del sistema
set

REM Applicazione dei criteri di gruppo (se in dominio o con criteri locali)
gpresult /r
Collegamento alle attività. whoami /groups e whoami /priv sono gli stessi strumenti usati nelle attività su utenti, gruppi e permessi: mostrano ciò che Windows mette davvero nel token di accesso al momento del login, non ciò che è scritto sulla carta.

11. Aprire un programma con un altro utente

Con runas si avvia un programma con le credenziali di un altro account, senza cambiare la sessione: è il modo classico per verificare "cosa vede" un altro utente (utile per i test dei permessi).

REM Apri il Blocco note come utente1 (verrà chiesta la password)
runas /user:utente1 notepad

REM Apri un Prompt dei comandi con l'identità di utente1
runas /user:utente1 cmd

REM Utente di dominio
runas /user:AZIENDA\mario cmd
OpzioneSignificato
/user:NomeUtenteL'account con cui eseguire il programma (locale o DOMINIO\utente)
/noprofileNon carica il profilo dell'utente (avvio più veloce, ambiente essenziale)
/envUsa l'ambiente dell'utente corrente invece di quello nuovo
/savecredSalva le credenziali (le richiede solo la prima volta) — comodo ma delicato
/netonlyLe credenziali valgono solo per l'accesso alle risorse di rete, non in locale
/smartcardChiede le credenziali tramite smart card
/showtrustlevelsElenca i livelli di attendibilità disponibili
Cosa runas non fa. Non "eleva" i privilegi e non aggira il controllo account utente (UAC): anche se l'altro utente è amministratore, il programma parte con il token standard. Serve inoltre che il servizio Logon secondario (Secondary Logon) sia attivo; nelle edizioni Home runas esiste ma l'alternativa grafica può mancare.

L'equivalente grafico, nelle edizioni Pro, è Maiusc + clic destro sul programma → Esegui come utente diverso. In ambienti professionali si usano anche strumenti come psexec -u (Sysinternals), che permettono di specificare utente e password in un unico comando.

12. Comandi simpatici da mostrare in classe

Non tutto deve essere permessi e ACL. Questi comandi fanno capire, divertendosi, che dal prompt si può controllare davvero il computer. Quelli che richiedono Internet usano curl, già incluso in Windows 10 e 11.

tree /f

Disegna l'albero completo di file e cartelle. Perfetto per "vedere" la struttura.

color 0A

Colora il prompt: 0 = sfondo nero, A = testo verde. Prova color /? per la tavolozza.

title Ciao classe

Cambia il titolo della finestra del prompt.

echo e l'arte ASCII

Con la redirezione si creano file di testo; incollando arte ASCII si fanno "disegni" da terminale.

REM Un albero da mostrare alla LIM
tree /f C:\Windows\System32\drivers\etc

REM Prompt "hacker" verde su nero
color 0A

REM Il titolo della finestra
title Benvenuti in TPS

REM Effetto macchina da scrivere: stampa riga per riga
echo Ciao classe! & echo Oggi si gioca col prompt. & echo Provate anche voi.

REM Apri le app di Windows dal prompt
notepad
calc
mspaint
explorer .
control
start https://www.microsoft.com

REM Il meteo in ASCII (serve Internet)
curl wttr.in/Roma

REM Un pappagallo che balla (serve Internet)
curl parrot.live

REM Animazioni ASCII: ciambella, pappagallo, Nyan Cat (serve Internet)
curl ascii.live/donut
curl ascii.live/parrot
curl ascii.live/nyan

REM Trasforma un testo in un QR code (serve Internet)
curl qrenco.de/Ciao%20TPS

REM "Star Wars" in ASCII: richiede il client telnet (funzionalità opzionale)
telnet towel.blinkenlights.nl
Se un comando "non esiste". telnet va prima attivato tra le funzionalità di Windows; curl è già presente da Windows 10 in poi. Senza Internet, i comandi che scaricano contenuti non funzionano: è un'occasione per parlare di rete e di ping.
Con moderazione. Un shutdown /s /t 0 o un msg * lanciato sul PC del compagno non è uno scherzo. Si sperimenta sempre sulla propria macchina virtuale, con lo snapshot pronto.

14. Scorciatoie e trucchi del prompt

  • Tab completa automaticamente nomi di file e cartelle; premuto più volte li scorre tutti.
  • Freccia su e Freccia giù richiamano i comandi precedenti; F7 apre l'elenco della cronologia.
  • Ctrl+C interrompe un comando; Esc cancella la riga scritta.
  • doskey /history stampa la cronologia; doskey /? permette di definire macro e alias.
  • cls pulisce lo schermo; color cambia i colori; title il titolo.
  • Trascinare un file nella finestra del prompt ne incolla il percorso completo: comodissimo per non sbagliare.
  • Il tasto Maiusc + clic destro su una cartella offre "Copia come percorso".
  • cmd /k esegue un comando e resta aperto; cmd /c esegue e chiude.

15. Buone pratiche e problemi comuni

SituazioneCosa fare
"Accesso negato"Il comando richiede privilegi: aprire il prompt come amministratore
"Il sistema non trova il percorso specificato"Controllare la cartella corrente (cd) e racchiudere tra virgolette i percorsi con spazi
Il comando non esisteVerificare il nome, il %PATH% con where, oppure usare comando /?
Ho cancellato qualcosa per sbaglioDal prompt non si passa dal Cestino: se è una VM, ripristinare lo snapshot
Output troppo lungoRedirigere in un file (> log.txt) o filtrare con | more / | findstr
Comando lungo e ripetitivoSalvarlo in un file .bat e richiamarlo per nome
Regola d'oro. Al prompt non esiste il "Ctrl+Z" universale e non esiste il Cestino: prima di lanciare un comando distruttivo, chiedersi dove si sta lavorando. In laboratorio si usa una macchina virtuale con snapshot: è fatta apposta per poter sbagliare.
