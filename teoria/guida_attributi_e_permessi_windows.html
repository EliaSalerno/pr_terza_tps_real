Comando CMD: attrib

Gestione degli Attributi di File e Cartelle

In Windows, ogni file possiede flag speciali (attributi) che ne determinano la visibilità, le modificabilità e le modalità di indicizzazione o backup. Sperimenta nel simulatore sottostante per capire l'impatto di ogni attributo.

Pannello di Controllo Attributi

Attiva o disattiva i flag per simulare gli attributi del file file.txt:

Stato predefinito: Solo `A` attivo

Stato Visuale File in Esplora Risorse

file.txt Visibile

Percorso: C:\Dati\file.txt

Prompt dei comandi (cmd.exe)
C:\Dati> attrib "C:\Dati\file.txt"
A C:\Dati\file.txt
C:\Dati> rem Esegui 'attrib +h' per impostare il file come nascosto

Dettaglio ed Esempi Pratici degli Attributi

R - Read-Only Sola Lettura

Se attivato, nessun programma o utente standard può modificare il contenuto del file o sovrascriverlo. Se si tenta di eliminare il file, il sistema restituirà un errore di Accesso Negato.

// Imposta Read-Only
attrib +r "C:\Dati\file.txt"
// Rimuovi Read-Only
attrib -r "C:\Dati\file.txt"
H - Hidden Nascosto

Nasconde il file o la cartella dalla normale vista di Esplora File e dal comando dir standard (richiede dir /a per essere visto da riga di comando).

// Imposta Nascosto
attrib +h "C:\Dati\file.txt"
// Mostra tutti i file inclusi i nascosti
dir /a
S - System Sistema

Contrassegna l'elemento come file essenziale del sistema operativo. Spesso usato insieme a H per nascondere file di sistema critici ed evitarne la cancellazione accidentale.

// Nascondi file di sistema (S+H)
attrib +s +h "C:\Dati\file.txt"
A - Archive Archivio

Indica al software di backup che il file è stato creato o modificato di recente. Dopo il backup, il software generalmente rimuove questo flag (-A) finché il file non cambia di nuovo.

// Disattiva flag Archivio
attrib -a "C:\Dati\file.txt"
I - Not Content Indexed Non Indicizzato

Dice al motore di indicizzazione di Windows (Windows Search) di non indicizzare il contenuto interno di questo file. Il file apparirà nelle ricerche solo tramite il nome, ma non attraverso la ricerca del testo al suo interno.

// Escludi dall'indicizzazione del contenuto
attrib +i "C:\Dati\file.txt"
Comando CMD: icacls

Sicurezza NTFS e Controllo Accessi (ACL)

Il comando icacls permette di visualizzare e modificare le liste di controllo di accesso (ACL) su file e cartelle in Windows. Esplora il significato delle sintassi riscontrate nei sistemi reali.

BUILTIN\Administrators:(I)(F)

Autorizzazione assegnata al gruppo locale degli amministratori di Windows.

  • (I) Inherited (Ereditato): Il permesso proviene dalla cartella superiore.
  • (F) Full Control (Controllo completo): Accesso illimitato al file/cartella.
Identificatore gruppo: Gruppo Amministratori Locale

NT AUTHORITY\SYSTEM:(I)(F)

Autorizzazione per l'account di sistema con i privilegi più elevati (LocalSystem).

  • (I) Inherited (Ereditato): Permesso ereditato dal contenitore padre.
  • (F) Full Control: Servizi di Windows hanno pieno controllo.
Account: Sistema Operativo (LocalSystem)

WINDOWS2\admin:(I)(F)

Permesso assegnato a uno specifico utente o gruppo di dominio/hostname (WINDOWS2).

  • (I) Inherited: Ereditato dalla cartella contenitore.
  • (F) Full Control: L'utente admin ha controllo totale.
Dominio/Host: WINDOWS2 | Utente: admin

Esempi Pratici di Comandi `icacls`

1. Concedere controllo completo a un utente:
icacls "C:\Dati\file.txt" /grant NomeUtente:(F)
2. Rimuovere permessi specifici a un gruppo:
icacls "C:\Dati\file.txt" /remove NomeGruppo
3. Salvare (backup) le ACL di una cartella:
icacls "C:\Dati" /save acl_backup.txt /t
4. Ripristinare le ACL da un file di salvataggio:
icacls "C:\" /restore acl_backup.txt
