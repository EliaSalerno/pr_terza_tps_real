Ambiente di test per lavorare sui permessi in Windows

L’idea è creare utenti, gruppi e cartelle di prova, così puoi sperimentare con icacls senza toccare dati reali. Apri il Prompt dei comandi come amministratore.

1. Creare gli utenti di prova

net user Mario Password123! /add
net user Luca Password123! /add
net user Anna Password123! /add

Per verificare:

net user
net user Mario

2. Creare un gruppo e aggiungere membri

net localgroup Progettisti /add
net localgroup Progettisti Mario /add
net localgroup Progettisti Anna /add

Per vedere i membri:

net localgroup Progettisti

Usare i gruppi è la buona pratica: si assegnano i permessi al gruppo, non ai singoli utenti.

3. Creare la struttura di cartelle

mkdir C:\Test\Progetto\Documenti
mkdir C:\Test\Progetto\Riservato
mkdir C:\Test\Pubblica

echo prova > C:\Test\Progetto\Documenti\file1.txt
echo segreto > C:\Test\Progetto\Riservato\file2.txt

4. Impostare i permessi di partenza

:: Interrompi l'ereditarietà e togli i gruppi larghi
icacls C:\Test\Progetto /inheritance:d
icacls C:\Test\Progetto /remove Everyone
icacls C:\Test\Progetto /remove Users
icacls C:\Test\Progetto /remove "Authenticated Users"

:: Il gruppo lavora sulla cartella
icacls C:\Test\Progetto /grant Progettisti:(OI)(CI)M

:: Luca può solo leggere
icacls C:\Test\Progetto /grant Luca:(OI)(CI)R

:: Riservato: Anna viene bloccata
icacls C:\Test\Progetto\Riservato /deny Anna:(OI)(CI)F

5. Controllare i permessi

:: ACL di una cartella
icacls C:\Test\Progetto

:: ACL ricorsiva su tutto il contenuto
icacls C:\Test\Progetto\* /t

:: Verifica la coerenza delle ACL
icacls C:\Test\Progetto\Riservato /verify

Per vedere chi è il proprietario:

dir /q C:\Test\Progetto

6. Testare davvero come un altro utente

Puoi aprire un prompt con le credenziali di un utente di prova:

runas /user:Mario cmd

Nella nuova finestra prova:

whoami
type C:\Test\Progetto\Documenti\file1.txt
echo nuovo >> C:\Test\Progetto\Documenti\file1.txt
del C:\Test\Progetto\Documenti\file1.txt

Così vedi subito se un permesso funziona o se ricevi «Accesso negato». Ripeti con Luca e Anna per confrontare i risultati.

7. Backup e ripristino delle ACL

Prima di fare esperimenti rischiosi, salva lo stato:

:: Salva
icacls C:\Test\Progetto /save C:\Test\acl_backup.txt /t

:: Ripristina (si indica la cartella PADRE)
icacls C:\Test /restore C:\Test\acl_backup.txt

Per tornare allo stato predefinito ereditato:

icacls C:\Test\Progetto /reset /t

8. Gestire il proprietario

:: Prendi possesso
takeown /f C:\Test\Progetto /r /d s

:: Assegna la proprietà a un utente
icacls C:\Test\Progetto /setowner Mario /t

9. Pulizia finale

rmdir /s /q C:\Test
net localgroup Progettisti /delete
net user Mario /delete
net user Luca /delete
net user Anna /delete

Consigli

  • Usa una macchina virtuale (Hyper-V, VirtualBox) se vuoi un ambiente completamente isolato.
  • Su Windows Home runas funziona, ma la gestione grafica dei gruppi locali è limitata: i comandi net restano la via più affidabile.
  • Se il PC è in un dominio, usa net group /domain o PowerShell (Get-Acl, Set-Acl) per gestire gli utenti di dominio.
  • Per un’analisi più dettagliata, esiste anche l’equivalente PowerShell: Get-Acl C:\Test\Progetto | Format-List.
