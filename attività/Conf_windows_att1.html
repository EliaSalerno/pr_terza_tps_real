Configurazione Windows – Attività 1

Utenti e file · Oracle VirtualBox 7.x · Windows 11

1. Attività preliminari

  1. Creare una macchina con nome “Windows” e accertarsi di salvare la macchina nella directory corretta.
    Nota. Nella procedura guidata di VirtualBox la cartella si sceglie nel campo “Cartella macchina”. Per Windows 11 lasciare attivi EFI, TPM 2.0 e Secure Boot (impostati automaticamente se il tipo è Windows 11). Assegnare almeno 4 GB di RAM, 2 CPU e 64 GB di disco.
  2. Associare al DVD virtuale il file ISO di Windows, avviare la macchina e installare Windows. In fase di installazione verrà richiesto il nome di un utente che sarà l’amministratore della macchina: chiamatelo admin con password admin.
    Nota. VirtualBox 7 offre l’“Installazione automatica”, dove si possono inserire direttamente utente e password. In alternativa, nell’installazione manuale di Windows 11 l’account Microsoft è richiesto: premere Maiusc+F10 e digitare start ms-cxh:localonly per creare un account locale. Scegliere l’edizione Pro e “Non ho un codice Product Key”.
  3. Effettuare due cloni della macchina appena installata, chiamandole “Windows 1” e “Windows 2”.
    Nota. Scegliere “Clone completo” e “Reinizializza l’indirizzo MAC di tutte le schede di rete”.
  4. Avviare la macchina “Windows 1”.
  5. Selezionare le proprietà di “Questo PC” (tasto destro su “Questo PC” in “Esplora file”).
  6. Scegliere “Cambia impostazioni” e modificare il nome e la descrizione della macchina, chiamandola WINDOWS-1.
    Nota. In Windows 11 il tasto destro apre Impostazioni → Informazioni su. Aprire “Impostazioni di sistema avanzate”, scheda “Nome computer”, pulsante “Cambia…”. La descrizione si imposta nella stessa scheda.
  7. Riavviare.
  8. Ripetere le operazioni d–g anche per la seconda macchina clonata, assegnando il nome WINDOWS-2.

2. Creazione di un utente

  1. Avviare la macchina “Windows 1”.
  2. Aprire il “Pannello di controllo”.
  3. Selezionare “Account utente”.
  4. Selezionare “Gestisci altro account”.
  5. Scegliere “Aggiungi un nuovo utente nelle impostazioni del PC” e poi “Aggiungi un altro utente a questo PC”.
  6. Scegliere “Non ho le informazioni di accesso di questa persona”.
  7. Scegliere “Aggiungi un utente senza account Microsoft”.
  8. Inserire l’utente utente1, la password (uguale al nome utente) e le domande per il recupero.
  9. Verificare la presenza di due utenti: quello creato in fase di installazione, che ha i diritti di amministratore, e l’ultimo creato, senza particolari diritti.
  10. Creare un secondo utente utente2.
Nota. In Windows 11 i passaggi e–g portano a Impostazioni → Account → Altri utenti, e l’opzione “senza account Microsoft” può non comparire. Alternative (da Prompt dei comandi come amministratore): net user utente1 utente1 /add, oppure lusrmgr.msc (solo edizione Pro). In questi casi non vengono chieste le domande di recupero.

3. Permessi per l’accesso a file e cartelle

  1. Disconnettersi da admin e connettersi come utente1.
  2. Creare nella cartella “Utenti\Pubblica\Documenti pubblici” la cartella cartella1.
  3. Rimuovere l’ereditarietà trasferendo i diritti a “cartella1”.
    Nota. Tasto destro (o Alt+Invio) → Proprietà → Sicurezza → Avanzate → “Disabilita ereditarietà” → “Converti le autorizzazioni ereditate in autorizzazioni esplicite”. In Windows 11 il menu contestuale è ridotto: usare “Mostra altre opzioni”.
  4. Eliminare i diritti per il gruppo “Interactive” (in Windows in italiano compare come “INTERATTIVO”). Vedere la pagina Microsoft sulle identità speciali: learn.microsoft.com – Identità speciali.
  5. Abilitare utente2 ad accedere a “cartella1” in sola lettura.
  6. Creare un file in “cartella1”.
  7. Verificare che utente2 possa leggere il file ma non modificarlo.
  8. Aggiungere a utente2 i diritti di modifica.
  9. Verificare che utente2 possa creare e modificare.
Suggerimento. Per provare i permessi, cambiare utente dal menu Start (icona utente) senza disconnettere gli altri. Prima di iniziare, creare uno snapshot della VM “Windows” pulita per poter ripetere l’esercizio.
