Creare la macchina virtuale Windows 11

Oracle VirtualBox 7.x · configurazione per le lezioni di TPS · senza codice di attivazione

1. Prima di iniziare

  • Computer ospitante: almeno 8 GB di RAM (meglio 16 GB), 64 GB liberi su disco (meglio SSD) e virtualizzazione attiva nel BIOS/UEFI (Intel VT-x oppure AMD-V/SVM).
  • VirtualBox 7.x installato dal sito ufficiale virtualbox.org. La versione 7 gestisce TPM 2.0 e Secure Boot, richiesti da Windows 11.
  • ISO di Windows 11: dal sito Microsoft, pagina “Scarica Windows 11”, sezione “Scarica l’immagine del disco (ISO)”, scegliere Windows 11 (ISO multi-edizione) e la lingua italiana. Non serve alcun account.

2. Creare la macchina

  1. Aprire VirtualBox e premere Nuova.
  2. Nome: Windows. In Cartella scegliere la directory corretta per le macchine virtuali (quella indicata dal docente o una cartella dedicata, ad esempio D:\VM).
  3. Immagine ISO: selezionare il file scaricato. Tipo e versione vengono riconosciuti: Microsoft Windows / Windows 11 (64-bit). Se compare il campo “Edizione”, scegliere Windows 11 Pro.
    Perché Pro. La Home non ha lusrmgr.msc, gpedit.msc né l’ingresso in dominio, strumenti necessari per le attività su utenti, gruppi e permessi.
  4. Lasciare deselezionata la voce “Skip Unattended Installation”: VirtualBox installerà Windows da solo.
  5. Pagina Installazione automatica: utente admin, password admin; il nome host può restare quello proposto (verrà cambiato nelle attività); lasciare vuoto il codice prodotto; spuntare Install Guest Additions.
  6. Pagina Hardware: RAM 4096 MB (8192 MB se il PC ha 16 GB), CPU 2, Enable EFI attivo.
  7. Pagina Disco rigido: creare un nuovo disco virtuale da 64 GB, lasciando deselezionata l’opzione “Pre-allocate Full Size” (il disco occupa spazio solo man mano che serve).
  8. Premere Fine, ma non avviare ancora la macchina: prima verificare le impostazioni del punto 3.

4. Installare Windows

Metodo consigliato: installazione automatica

Avviare la macchina e attendere. Windows si installa da solo e si riavvia più volte (10-20 minuti): non premere tasti e non spegnere. Alla fine si arriva al desktop già connessi come admin.

Metodo manuale (se si è scelto di saltare l’installazione automatica)

  1. All’avvio premere un tasto quando compare “Press any key to boot from CD or DVD”.
  2. Scegliere lingua e tastiera italiana, poi “Installa ora”.
  3. Selezionare “Non ho un codice Product Key” e poi l’edizione Windows 11 Pro.
  4. Scegliere “Personalizzata”, selezionare il disco non allocato e proseguire.
  5. Al momento della creazione dell’account, se viene richiesto l’account Microsoft, premere Maiusc+F10 e digitare start ms-cxh:localonly per creare un utente locale admin con password admin.
Attenzione. Questo trucco per l’account locale dipende dalla build di Windows e potrebbe non funzionare nelle versioni più recenti. In tal caso usare l’installazione automatica di VirtualBox.

5. Configurare Windows dopo l’installazione

  1. Guest Additions. Se non sono state installate in automatico: menu Dispositivi → Inserisci immagine CD delle Guest Additions, aprire l’unità CD in Esplora file, eseguire VBoxWindowsAdditions.exe e riavviare. Si ottengono schermo ridimensionabile, mouse integrato e appunti condivisi.
  2. Verifica edizione. Premere Win+R, digitare winver: deve risultare Windows 11 Pro. Provare anche lusrmgr.msc: deve aprirsi.
  3. Lingua, tastiera e fuso orario. Impostazioni → Ora e lingua: italiano, tastiera italiana, fuso orario corretto.
  4. Sospendere gli aggiornamenti. Impostazioni → Windows Update → “Sospendi aggiornamenti”, così Windows non si aggiorna durante la lezione.
  5. Alimentazione. Impostazioni → Sistema → Alimentazione: schermo e sospensione su “Mai”.
  6. Esplora file. Visualizza → Mostra: attivare “Estensioni nomi file” ed “Elementi nascosti”, utili per lavorare sui permessi.

6. Uso senza codice di attivazione

Windows 11 installato senza chiave funziona con queste differenze:

FunzionaNon disponibile o limitato
Creazione e gestione di utenti e gruppi, permessi NTFS, condivisioni di rete, PowerShell e prompt dei comandi, criteri di sicurezza locali, Utilità di pianificazione, ipconfig, ping Personalizzazione (sfondo, colori, temi, schermata di blocco) e filigrana “Attiva Windows” in basso a destra
Licenza. Per una demo in classe questa modalità è sufficiente, ma per un uso prolungato Windows richiede formalmente una licenza. Alternative legittime: l’Evaluation Center di Microsoft (microsoft.com/evalcenter), con ISO di Windows 11 Enterprise valida 90 giorni e senza filigrana, oppure le licenze della scuola (Microsoft 365 Education, Azure Dev Tools for Teaching), da chiedere all’amministratore IT.

7. Snapshot, cloni ed esportazione

  1. Snapshot. Con la macchina spenta: Strumenti → Istantanee → Crea, nome “Installazione pulita”. Se qualcosa va storto, si ripristina in pochi secondi.
  2. Cloni per le attività. Tasto destro sulla macchina → Clona → nome Windows 1 (poi Windows 2) → tipo Clone completo → spuntare “Reinizializza l’indirizzo MAC di tutte le schede di rete”.
  3. Esportare per altri PC dell’aula. File → Esporta servizio virtualizzato, formato OVF 2.0, file .ova. Sugli altri PC: File → Importa servizio virtualizzato, con la stessa opzione di reinizializzazione del MAC. Verificare che la macchina si avvii correttamente su un PC prima di distribuirla a tutti.

8. Problemi frequenti

ProblemaSoluzione
Errore di virtualizzazione non disponibileAttivare VT-x/AMD-V (o “SVM Mode”) nel BIOS/UEFI del PC ospitante.
VM molto lenta su PC WindowsHyper-V, WSL2 o “Integrità della memoria” possono rallentare VirtualBox. Disattivarli da “Attiva o disattiva funzionalità di Windows” oppure, da prompt come amministratore, bcdedit /set hypervisorlaunchtype off e riavviare.
Non parte dal DVD / shell UEFISpegnere, riavviare e premere subito un tasto. Dalla shell UEFI digitare exit e scegliere il DVD dal Boot Manager.
“Questo PC non può eseguire Windows 11”Controllare TPM 2.0, Secure Boot e RAM (almeno 4 GB). In alternativa, nel programma di installazione premere Maiusc+F10 ed eseguire: 
reg add HKLM\SYSTEM\Setup\LabConfig /v BypassTPMCheck /t REG_DWORD /d 1 /f
reg add HKLM\SYSTEM\Setup\LabConfig /v BypassSecureBootCheck /t REG_DWORD /d 1 /f
reg add HKLM\SYSTEM\Setup\LabConfig /v BypassRAMCheck /t REG_DWORD /d 1 /f
Il mouse resta “bloccato” nella finestraPremere il tasto Host (di default Ctrl destro) e installare le Guest Additions.
Risoluzione fissa e piccolaInstallare le Guest Additions e riavviare.

9. Controllo finale

  • La macchina si chiama “Windows” ed è nella cartella corretta.
  • Edizione Windows 11 Pro (winver), utente admin / admin.
  • lusrmgr.msc si apre.
  • Guest Additions installate: schermo ridimensionabile e appunti condivisi.
  • Aggiornamenti sospesi e sospensione disattivata.
  • Snapshot “Installazione pulita” creato.
  • Cloni “Windows 1” e “Windows 2” creati con MAC reinizializzato (quando servono).
