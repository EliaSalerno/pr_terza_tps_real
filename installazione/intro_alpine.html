Alpine Linux in Macchina Virtuale

Guida passo-passo a configurazione, Bash, rete, NTP e personalizzazione

1. Rete e Installazione Base

Per condividere la connessione Internet del PC reale (Host) con Alpine Linux (Guest):

  • Impostazione VM (VirtualBox / VMware): Imposta la scheda di rete in modalità NAT.
  • Installazione: Avvia il sistema live ed esegui lo script guidato:
setup-alpine
  • Seleziona l'interfaccia eth0 e scegli il metodo dhcp.
  • Completa l'installazione su disco con setup-disk e riavvia.

2. Gestione Repository e Soluzione Errori

Se riscontri l'errore WARNING! No mirror found o ERROR: unable to select package, occorre ripristinare o verificare i repository.

Verificare la Versione di Alpine

cat /etc/alpine-release

Ripristinare /etc/apk/repositories (Esempio per v3.24)

Puoi sovrascrivere direttamente il file dei repository eseguendo:

cat <<EOF > /etc/apk/repositories
http://dl-cdn.alpinelinux.org/alpine/v3.24/main
http://dl-cdn.alpinelinux.org/alpine/v3.24/community
EOF

Aggiorna sempre l'indice dopo la modifica:

apk update

3. Configurazione Bash come Shell Predefinita

Di default Alpine utilizza la shell ash. Per installare e attivare la Bash:

# 1. Installa Bash e il completamento automatico
apk add bash bash-completion

# 2. Imposta Bash come shell di default per root
sed -i -e 's/root:\/bin\/sh/root:\/bin\/bash/g' /etc/passwd

# 3. (Opzionale) Per un utente non-root
apk add shadow
chsh -s /bin/bash nome_utente

Riavvialo con exit e fai di nuovo il login per applicare le modifiche, oppure esegui subito exec bash.

# Verifica la shell attiva
echo $SHELL
Nota: Differenze con Ubuntu
Alpine usa apk invece di apt, OpenRC (rc-service) invece di systemd (systemctl) e la libreria musl libc invece di glibc.

4. Sincronizzazione Ora (NTP Client)

Per le macchine virtuali (che possono perdere il sincrono dell'ora quando vengono messe in pausa), il client NTP consigliato è Chrony.

# Installazione e avvio di Chrony
apk add chrony
rc-update add chronyd default
rc-service chronyd start

# Verifica dello stato di sincronizzazione
chronyc tracking

5. Editor di Testo Micro

Micro è un editor da terminale moderno e intuitivo che supporta le scorciatoie classiche (Ctrl+C, Ctrl+V, Ctrl+S, Ctrl+Q).

# Installazione
apk add micro

# Utilizzo
micro nome_file.txt

6. Ingrandire i Font del Terminale

Se i caratteri della console di VirtualBox sono troppo piccoli, puoi installare ed estendere i font di sistema:

# 1. Installa kbd e il pacchetto font terminus
apk add kbd font-terminus

# 2. Prova subito il font grande (32px)
setfont /usr/share/consolefonts/ter-v32n.psf.gz

# 3. Impostalo in modo permanente all'avvio
echo 'consolefont="ter-v32n.psf.gz"' > /etc/conf.d/consolefont
rc-update add consolefont boot

Alternativa tramite VirtualBox

Vai nel menu in alto della finestra di VirtualBox: Visualizza (View) → Fattore di scala (Scale Factor) → Seleziona 150% o 200%.
